About the playground

The seiton playground is a static page: after the WASM runtime loads, it parses and lints GitHub Actions workflow and action metadata YAML in your browser. Your YAML is not uploaded to a server for analysis.

You can edit YAML in the editor, load built-in samples, open a document from a URL you enter (your browser requests that URL directly), or use Share to store the document in the page URL. Very large snippets may exceed browser URL length limits when sharing.

There are practical limits to what the playground can do:

  • It performs static checks only—it does not run workflows, actions, or run: steps on GitHub’s infrastructure.
  • Fetch by URL only contacts the host you specify; the playground does not proxy your YAML through another backend.
  • Apply all fixes runs locally; remediations that need network lookups (for example some pinning or digest updates) are skipped. See the button tooltip for more details.
  • Behavior matches the bundled Seiton build. A version badge appears in the header, which reflects this deployment.

The source code is available on GitHub.
